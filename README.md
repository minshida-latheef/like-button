# ❤️ Like Button

A small yet interactive web project that brings a simple social media feature to life!

## Project Description

This project is a simple Like Button created using HTML, CSS, and JavaScript. It allows users to interact with a button and toggle between liked and unliked states with a visual animation.

## What Can You Do?

- Click to like ❤️
- Click again to unlike
- Enjoy interactive button animations
- Get instant visual feedback
- Experience a simple and clean design

## Tech Stack

- HTML – Structure
- CSS – Styling and animations
- JavaScript – Interactive functionality
